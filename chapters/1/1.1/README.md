# 1.1 - Getting Started

Compile with: `gcc src/main.c -o program`

- Only run any of these commands if you have compiled it.
- People who haven't compiled it will have to run the pre-compiled executables to run.
- Run the pre-compiled executables in [the executables folder](./executables/) for your os
Run with: `./program`

[executables](./executables/) | [main.c](./src/main.c)

## important stuff:
- `#include` includes different files from either the standard C library or any library:
```c
#include <file.h>/"file.h"
```

- `\n` prints a newline.

## exercises:
- Exercise 1-1: Run the "Hello, world!" program on your system. Experiment with leaving out parts of the program, to see what error messages you get.
- Exercise 1-2: Experiment to find out what happens when `print`'s argument string contains `\c`, where `c` is some character not listed above.
